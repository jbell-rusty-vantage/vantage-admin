# Vantage Admin Dashboard

Internal web application for lead search, bookings, cancellations, Granot intakes, analytics, and Workflow Observational.

**Platform domain language:** [`../CONTEXT.md`](../CONTEXT.md)

**ADRs:** [`../docs/adr/`](../docs/adr/)

**Agent consumer rules:** [`../docs/agents/domain.md`](../docs/agents/domain.md)

**Overview desk (admin-local pointer):** live `/` is `HomeOverview` — Owner Waiting for you Booking intakes from the existing open-case list, this-week pulse, compact all-time, create Booking/Cancellation. Cancellation intakes are not on Overview. Not Daily View, not a sitemap, not a second Analytics. Map: [`.cursor/rules/project-organization.mdc`](.cursor/rules/project-organization.mdc).

**Planned (admin-local pointer, not a glossary term):** Owner Daily View is intended as its own `/daily` page. It is not implemented and is not current `/` Overview behavior. See [`uxdocs/owner-daily-view-planned.txt`](uxdocs/owner-daily-view-planned.txt).

**Lead Conversations tab (admin-local pointer):** shipped Owner-only `/conversations` example surface. One seeded Lead Conversation. Vercel AI Gateway automation is not authorized and is not live. Contract: [`uxdocs/lead-conversations-tab-specification.md`](uxdocs/lead-conversations-tab-specification.md). Domain words stay in the root glossary.

**Dashboard chrome (admin-local pointer):** Sidebar destinations are grouped Today / Records / People / Insight / System in `components/layout/dashboard-nav.tsx`. Links stay compact under those headers. `visibleDashboardNav(role)` stays a flattened destination list; Owner order still starts Overview, Live Events, Lead Conversations. System order includes Owner-only **Granot Lifecycle** (`/granot-lifecycle`) after Operations Registry and before Ingestion, then Owner-only **Extension** (`/extension`) for create, edit, and delete of Extension User logins (roles checkboxes). No Settings tab. No New badges. Grouping labels are not Owner Daily View. Map: [`.cursor/rules/project-organization.mdc`](.cursor/rules/project-organization.mdc).

**Extension tab (admin-local pointer):** shipped Owner-only `/extension`. Create, edit, and delete an Extension User. Roles are checkboxes (Owner, Sales, Customer Service); one person may hold Sales and Customer Service. List shows joined labels. Leave the password blank on edit to keep it. A leftover Employee login lists as that pair. Not Agents. Role meanings stay in the root glossary. Pack: [`../granot_sync_extensions_and_services/docs/extension-user-management/README.md`](../granot_sync_extensions_and_services/docs/extension-user-management/README.md).

**Operations Registry (admin-local pointer):** `/operations-registry` owns agents, merchants, lead sources, Granot names, inbound numbers, Moving Carriers, lead costs, Legacy CPL, and Changes. Owner can edit Moving Carriers, including Granot Carrier Code; Admin is read-only. Legacy CPL stays a read-only compatibility view. `/settings` permanently redirects to `?tab=moving-carriers` and is not owner-only — Admin can follow it onto Operations Registry. Old `?tab=` values `sources`, `granot-sources`, `ringcentral`, and `cpl` still resolve for one release. Map: [`.cursor/rules/project-organization.mdc`](.cursor/rules/project-organization.mdc).

**Lead Costs Owner editing (admin-local pointer, not a glossary term):** planned pack LCE-01–05. Live `/operations-registry?tab=lead-costs` still has Simple / Advanced / Corrections; Advanced still speaks `add_future` / `correct_period` / `replace_schedule` and Period IDs. The contract makes Advanced **By date**: Feed + From + Through (or Ongoing) + Amount via server `set_range`. Current rates / Existing leads are label and copy changes. Not Legacy CPL. Not Analytics. Pack: [`../vantage-main-server/docs/lead-costs-owner-editing/README.md`](../vantage-main-server/docs/lead-costs-owner-editing/README.md). Domain words stay in the root glossary.

**Live Events tab (admin-local pointer):** shipped Owner-only `/live-events`. Granot live webhook SSE moved out of Ingestion to a top-level Owner sidebar tab (first item under Overview). Contract: [`uxdocs/live-events-tab-specification.md`](uxdocs/live-events-tab-specification.md). Domain words stay in the root glossary.

**Daily Operations (admin-local pointer, not shipped):** planned Owner-only `/daily` in the Today group, after Overview and before Live Events. Live categorized feed + running New York-day counts + origin/company aggregates + pace vs yesterday. Upstash Redis is the doorbell; Mongo remains system of record. Not Live Events, not Analytics, not Observational. Contract: [`../vantage-main-server/docs/daily-operations/daily-operations-pre-specification.md`](../vantage-main-server/docs/daily-operations/daily-operations-pre-specification.md). Domain words stay in the root glossary.

**Form Lead contact snapshots (admin-local pointer):** shipped. `/form-leads` and `/duplicate-form-leads` show Form submitted vs Granot contact (chip + Contacts detail). Browse and typeahead search live fields plus both snapshots. Contract: [`../vantage-main-server/docs/form-lead-contact-snapshots-display-and-search-specification.md`](../vantage-main-server/docs/form-lead-contact-snapshots-display-and-search-specification.md). Domain words stay in the root glossary.

**Call Lead contact provenance (admin-local pointer):** shipped. `/call-leads` and `/duplicate-call-leads` keep Name / Phone as **Called** and show a Granot chip plus Called / Granot Contact cards. Browse, typeahead, and search include the Granot phone. Contract: [`../vantage-main-server/docs/call-lead-contact-provenance/README.md`](../vantage-main-server/docs/call-lead-contact-provenance/README.md). Domain words stay in the root glossary.

**Manual tab (admin-local pointer):** shipped Owner-only `/manual` with two options on that route: Create a Lead (`/manual`) and Connect Booking to Lead (`/manual?tab=attach`). Create picks the Source Company the Owner already knows (Top10 Inbounds, not the parent company) via `POST /api/v1/form-leads` / `POST /api/v1/call-leads` with `ingestion_origin` assigned as Vantage Admin. Attach is a two-panel find: booking by job number, lead by Source Company / phone / name / email / ref number / job number, then connect. Connect also remains on `/bookings` detail. Not Booking Lead Reconciliation. Map: [`.cursor/rules/project-organization.mdc`](.cursor/rules/project-organization.mdc). Domain words stay in the root glossary.

**Booking intake robustness (admin-local pointer):** BILA-01–BILA-03 shipped — `/intakes` Find the right customer searches any-known-contact and shows Form submitted vs Granot (shared helper in `form-lead-contacts.tsx`). Confirm may omit a Lead; unique high auto-attaches; otherwise Master Booked only. `/bookings` detail hosts Connect Booking to Lead for a Leadless Booking (Stored lead column + in-place search). `/manual?tab=attach` is a two-panel find of its own. Not `/bookings/reconciliation`. Pack: [`../vantage-main-server/docs/booking-intake-lead-attachment/README.md`](../vantage-main-server/docs/booking-intake-lead-attachment/README.md). Domain words stay in the root glossary.

**Job Timeline Enhancement (admin-local pointer):** JTE-04 shipped. Live `/job-timeline?job=` renders the server-evaluated v2 page. Coverage chips remain the v1 fallback only. Live proof and deep links are JTE-05. Orientation: [`uxdocs/HANDOFF-job-timeline-enhancement.md`](uxdocs/HANDOFF-job-timeline-enhancement.md). Contract: [`../vantage-main-server/docs/job-number-timeline/README.md`](../vantage-main-server/docs/job-number-timeline/README.md).

**Operational surfaces (admin-local pointer, not a glossary term):** shipped / live (OSE-01–05). `OperationalResourcePage` still composes the eight list routes. The detail `SidePanel` is destination-tabbed (`?panel=`). List rows have an identity cell, status chips, one sticky-right Actions cluster, and a selected-row highlight (`?record=`). Owner production lists (Form/Call/Duplicate leads, Bookings, Cancellations) show a Sheet checkbox column: select a row and **Check Google Sheet contains** appears so the owner can confirm the record is in the Google Sheet. The filter sidebar groups Find / Status / Attribution / Record fields (same URL keys; not Observational `FilterBar`). Not Daily View. Contract: [`../vantage-main-server/docs/operational-surfaces/README.md`](../vantage-main-server/docs/operational-surfaces/README.md). Domain words stay in the root glossary.

**Granot Lifecycle surfaces (admin-local pointer, not a glossary term):** GLS-01 and GLS-03 shipped. Ingestion: Granot workflow first (`/ingestion/granot`, HTTP Automation only; `GranotNavigation` removed), then Best Relocation (`INGESTION_COPY`). Owner-only System tab **Granot Lifecycle** sits after Operations Registry and before Ingestion; `/granot-lifecycle` and `/granot-lifecycle/receipts` (`GRANOT_LIFECYCLE_RECEIPTS_HREF`) render Receipts. Subnav is Receipts, Health (exclusive active). Receipts owns URL filters, stacked unmasked Name / Phone / Email, wrapping event-type chips, View payload `SidePanel` on `?receipt=` (credential-redacted `granot_statement`), and deep-links Open Job Timeline / Open Intake. Pack spec §6 masked list / “no payload” is superseded — list GET: [`../vantage-main-server/docs/knowledge/granot-lifecycle/live-receipts.md`](../vantage-main-server/docs/knowledge/granot-lifecycle/live-receipts.md). Health lives at `/granot-lifecycle/health` (`GRANOT_LIFECYCLE_HEALTH_HREF`); Admin can open Health, not Receipts. Redirects: `/ingestion/granot/lifecycle` → `/intakes`; old Health → `/granot-lifecycle/health`; jobs/:jobNo → `/job-timeline?job=`. Job Timeline stays `/job-timeline`. Live Events SSE stays `/live-events`. Not Operations Registry, not an Observational tab. Pack index: [`../vantage-main-server/docs/granot-lifecycle-surfaces/README.md`](../vantage-main-server/docs/granot-lifecycle-surfaces/README.md). Domain words stay in the root glossary.

**Agents list metrics (admin-local pointer):** `/agents` reads browse-enriched `booking_count`, `total_binder_amount` (this Agent’s allocations), `total_deposit_amount` (once per Booking), `cancellation_count`, and `cancellation_rate` (0–1; Cancel Rate formats as percent). Date range is book date, not Agent created-at. Server: [`../vantage-main-server/docs/knowledge/services/admin-search.md`](../vantage-main-server/docs/knowledge/services/admin-search.md). Not Analytics `agent-performance` (that report still credits full deposit per unwound allocation). Domain words stay in the root glossary.

Overview table mode selects Executive Summary / Deposit Mix / Receiver Attribution. Overview table Cost row is Refunds. Receiver source-breakdown header is Source Granularity. Map: [`.cursor/rules/project-organization.mdc`](.cursor/rules/project-organization.mdc). Domain words stay in the root glossary.
