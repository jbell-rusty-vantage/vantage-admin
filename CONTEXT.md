# Vantage Admin Dashboard

Internal web application for lead search, bookings, cancellations, Granot intakes, analytics, and Workflow Observational.

**ADRs:** [`../docs/adr/`](../docs/adr/)

**Overview desk (admin-local pointer):** live `/` is `HomeOverview` — Owner Waiting for you Booking intakes from the existing open-case list, this-week pulse, compact all-time, create Booking/Cancellation. Cancellation intakes are not on Overview. Not Daily Operations, not a sitemap, not a second Analytics. Map: [`.cursor/rules/project-organization.mdc`](.cursor/rules/project-organization.mdc).

**Not Overview:** Daily Operations is the shipped Owner-only `/daily` page, not current `/` Overview behavior. Do not implement from [`uxdocs/owner-daily-view-planned.txt`](uxdocs/owner-daily-view-planned.txt). See the Daily Operations pointer below.

**Lead Conversations tab (admin-local pointer):** shipped Owner-only `/conversations` example surface. One seeded Lead Conversation. Vercel AI Gateway automation is not authorized and is not live. Contract: [`uxdocs/lead-conversations-tab-specification.md`](uxdocs/lead-conversations-tab-specification.md). Domain words stay in the root glossary.

**Dashboard chrome (admin-local pointer):** Sidebar destinations are grouped Today / Records / People / Insight / System in `components/layout/dashboard-nav.tsx`. Links stay compact under those headers. `visibleDashboardNav(role)` stays a flattened destination list; Owner order still starts Overview, then Daily Operations, then Live Events, Lead Conversations. System order includes Owner-only **Granot Lifecycle** (`/granot-lifecycle`) after Operations Registry and before Ingestion, then Owner-only **Extension** (`/extension`) for create, edit, and delete of Extension User logins (roles checkboxes). No Settings tab. No New badges. Grouping labels are not Daily Operations. Map: [`.cursor/rules/project-organization.mdc`](.cursor/rules/project-organization.mdc).

**Extension tab (admin-local pointer):** shipped Owner-only `/extension`. Create, edit, and delete an Extension User. Roles are checkboxes (Owner, Sales, Customer Service); one person may hold Sales and Customer Service. List shows joined labels. Leave the password blank on edit to keep it. A leftover Employee login lists as that pair. Not Agents. Role meanings stay in the root glossary. Pack: [`../granot_sync_extensions_and_services/docs/extension-user-management/README.md`](../granot_sync_extensions_and_services/docs/extension-user-management/README.md).

**Operations Registry (admin-local pointer):** `/operations-registry` owns agents, merchants, lead sources, Granot names, inbound numbers, Moving Carriers, lead costs, Legacy CPL, and Changes. Owner can edit Moving Carriers, including Granot Carrier Code; Admin is read-only. Legacy CPL stays a read-only compatibility view. `/settings` permanently redirects to `?tab=moving-carriers` and is not owner-only — Admin can follow it onto Operations Registry. Old `?tab=` values `sources`, `granot-sources`, `ringcentral`, and `cpl` still resolve for one release. Map: [`.cursor/rules/project-organization.mdc`](.cursor/rules/project-organization.mdc).

**Daily Operations (admin-local pointer):** shipped Owner-only `/daily` after Overview. Category panels plus complementary Arrivals. DOP-10: tiles and panel headers show `%` versus yesterday-by-now with a visible yesterday / day-before line and an Hourly rhythm chart; Arrivals is a sticky live rail beside the panel grid on `xl`+; cards show every stored fact; every Daily Operations Event kind has a default colour tone with Owner overrides in `localStorage` (`vantage-admin-daily-kind-colors`, Colours toolbar panel). Quiet priorities / Sheet Sync / Colours sit in the board toolbar. **DOP-11:** `?lane=` is a solo Panel view (`data-panels-view="solo"`) — only that Daily Operations Panel renders; **All panels** clears `lane` (replaces DOP-10 expand-in-place). **Open all** / **Open full stream** opens a full-stream overlay. `lanesNeedingBackfill` includes `exception` (a panel count must not sit above an empty stack). The Exceptions panel also shows an in-memory Lead that carries `zip_miss` when the dedicated `exception.zip_missing` fact is not in memory. Count with no cards: `This count is on the board; the cards are still loading.` Arrivals Card is height-capped; the card list (`data-arrivals-scroll`) is the scroll region (header and Open all stay pinned). Like-hour `*_by_now` follows the browser clock. Tiles / `+N` count per `event` (Admin ignores the SSE `metrics` frame). Snapshot resyncs every 5 minutes while visible, after hidden ≥ 240s, and on New York day rollover. Load earlier is per lane. Not Daily View. Not Live Events. Not the 2026-08-19 tabbed layout. Confirm stays on `/intakes`. Contract: [`../vantage-main-server/docs/daily-operations/daily-operations-specification.md`](../vantage-main-server/docs/daily-operations/daily-operations-specification.md). Pointer: [`../vantage-main-server/docs/knowledge/services/daily-operations.md`](../vantage-main-server/docs/knowledge/services/daily-operations.md).

**Manual tab (admin-local pointer):** shipped Owner-only `/manual` with two options on that route: Create a Lead (`/manual`) and Connect Booking to Lead (`/manual?tab=attach`).
