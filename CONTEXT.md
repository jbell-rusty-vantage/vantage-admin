**Dashboard redesign (admin-local pointer, 2026-10-06):** the sidebar is six destinations — Today (`/`), Leads (`/leads`), Bookings (`/bookings`), Outreach Desk, Insights (`/insights`), Setup (`/setup`) — drawn in the Outreach Desk's bubbly look app-wide (`--crm-*` tokens, `components/ui/crm/`, theme scoped to `[data-ui="crm"]` on the dashboard shell). **Outreach Desk (admin-local pointer):** `/outreach-desk` is the Sales Outreach Desk, a "Lead outreach" app with its own shell (route group `(desk)`), outside the Admin sidebar. Frames: `?view=team` (Owner/Manager default: four goal/overdue cards, Operations today strip, Daily call goals, Leads needing attention), `?view=my` (Rep default; Owner/Manager add `agent=<id>`: goal card, New/Quoted/All tabs, Needs contact / All active, queue and selected-lead panel with Copy job #), `?view=activity`, `?view=settings` (Owner controls, roster, closures, restrictions, enrollment; Manager attendance only), and Owner-only `?view=numbers` / `?view=accounts` (today's Numbers and RingCentral Accounts, moved unchanged). Roles: Owner, the new Manager (desk + Today → Operations only) and Rep; a generic Admin gets no desk. `/sales-intelligence*` permanently redirects here (`?number=` → `view=numbers&number=`, `view=reps` → `view=accounts`). The bubbly look is now the app-wide CRM token set (`--crm-*` in `app/globals.css`, `components/ui/crm/`; Owner decision 2026-10-05); the Desk keeps its own shell and `od-*` primitives, aliased to those tokens in `components/outreach-desk/styles/outreach-desk.css`. The server DTO is the authority: a null count is Pending, cadence-off metrics read Unavailable (`coverage_incomplete`: waiting for capture coverage), a channel whose deadline capture can't prove yet (`verification.state: unverified`) reads "Due — not yet verified" and never overdue, a rep with no calls once capture is complete (`actual_basis: no_activity_recorded`) reads a real 0, the freshness chips say why a source is delayed (the server's `reason` in words), and the browser never computes overdue or order. Packet: [`docs/sales-outreach-desk/`](docs/sales-outreach-desk/README.md); map: [`.cursor/rules/project-organization.mdc`](.cursor/rules/project-organization.mdc).
