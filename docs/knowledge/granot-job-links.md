# Outreach Desk: Open in Granot

Every Rep, Owner and Manager can use **Open in Granot** from the queue row and selected card's side panel. Both controls appear beside the existing **Copy job #**, which remains available everywhere. Pending Job Numbers have no Granot button. The side panel uses the server's `granot_link_available` grant; each row is already scoped by the queue API. The retrieval endpoint independently authorizes every request: Reps need their current canonical assignment or freshly verified shared Pool access; coordinators retain their existing read scope. The Josh-only pilot restriction was removed at the Owner's request on 2026-10-30.

The button opens a blank tab immediately, shows a loading message and POSTs `outreach/:id/granot-link` through the existing authenticated, signed BFF. It redirects that tab only after parsing a verified exact Eagle `chargeswc` URL. The tab's opener is cleared. A failure closes the loading tab and shows an inline retry message; popup blocking is explained in the card. Clicking or using the keyboard on a row control does not select the row. No request runs merely because a card is opened. A successful side-panel attempt reveals **Refresh link**, which explicitly bypasses the saved cache. Each click reauthorizes; the UI does not retain a directly reusable href.

Each user must sign in to Granot in that browser first. The generated URL is refreshable navigation evidence; its UUID is not permanent job identity. Granot cookie/session failures happen on the external page and cannot be inspected cross-origin by the Desk. Refresh is the recovery action after signing in or encountering a stale link. Individual users' browser sessions are separate from verified server retrieval.

The server owns the optional Lead cache, ten-minute reuse, provider search, shared account lease, job identity verification and assignment recheck. The Admin stores no Granot credentials, cookies or main login token. No new Admin environment settings or migration are needed. Rollback is deployment of the preceding Admin/API; additive Lead cache entries may remain. Server contract: `vantage-main-server/docs/knowledge/services/sales-outreach-desk.md`.
